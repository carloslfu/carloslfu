# Carlos Galarza

I work on Executable Rationality and efficient AI: making machine cognition
explicit, runnable, and efficient. Independent, based in Colombia, building
in the open for over a decade.

Things of mine you can run:

- [slotstream](https://github.com/carloslfu/slotstream): a 105 GB
  mixture-of-experts model on a 48 GB Mac, streamed from SSD. One Swift
  binary, and every number ships with its measurement.
- [db.md](https://github.com/carloslfu/db.md): the open standard for
  databases in plain markdown files. [Sevra](https://www.sevrahq.com) is its
  managed home.
- [Math a Server Can't See](https://www.carlosgalarza.com/guides/fhe-playground):
  real homomorphic encryption in your browser, against a server that never
  sees your numbers.

I help teams run open models on hardware they already own, and fix
production agent workflows that fail in ways nobody can reproduce.
